# 캐리캐리체인지 3D 뷰어 (gh-pages)

이 브랜치는 GitHub Pages 배포 전용이다. `main` 으로 PR 이나 merge 하지 않는다.

- 보기 페이지: `index.html` (레포의 `scene.json` 배치를 보여 줌)
- 편집 페이지: `editor.html` (부품 추가, 이동, 회전, 길이 조절)

## 배치 수정하는 법

1. 편집 페이지에서 부품을 배치한다.
2. 오른쪽 위 **적용** 을 누른다. gh-pages 브랜치의 `scene.json` 이 바로 커밋된다.
3. 1~2분 뒤 사이트에 들어오는 모든 사람에게 그 배치가 보인다.

처음 적용할 때 GitHub 토큰을 한 번 입력한다. 토큰은 그 브라우저(localStorage)에만 저장되고 레포에는 올라가지 않는다.

- 만드는 법: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 권한은 `public_repo` 하나만, 만료 기간 설정
- 레포 주인이 아닌 팀원은 먼저 레포 협업자(Settings → Collaborators)로 초대받아야 한다.
- 편집을 시작한 뒤 다른 사람이 먼저 적용했으면 덮어쓸지 물어본다.
- 공용 컴퓨터에서 썼다면 적용 창의 **토큰 지우기** 를 누른다.
- 편집하다가 창을 닫아도 같은 브라우저에서 다시 열면 이어서 편집할 수 있다.

## 내 컴퓨터에서 확인하기

파일을 더블클릭해서 열면 브라우저가 `scene.json` 읽기를 막는다. 레포 폴더에서 아래를 실행한 뒤 http://localhost:8000 으로 연다.

```bash
python3 -m http.server
```

## 조작 규칙

- 부품은 이동과 회전만 된다. 크기 조절은 없다.
- 길이가 있는 부품(프로파일, 샤프트, 스펀지 브러시)만 길이를 바꿀 수 있다.
- 단위는 mm, 위쪽이 +Y 이다. 바닥 격자 한 칸은 100 mm.

## 조립 규칙 (js/assembly.js)

부품을 끌어서 결합 위치 근처(25 mm 이내)로 가져가면 자석처럼 붙는다. Alt 를 누른 채 끌면 자석 없이 움직인다.
규칙을 어긴 부품도 놓을 수 있지만 빨간색으로 표시되고 경고 목록에 나온다.

| 부품 | 붙는 곳 | 자동으로 생기는 체결 부품 |
| --- | --- | --- |
| 프로파일 | 다른 프로파일 옆면에 끝면 (T자, 끝에 맞추면 ㄱ자), 끝면끼리 (일자) | T자: 코너 브라켓 2개, ㄱ자: 1개, 일자: 연결 플레이트 2개 + M5 볼트, T너트 |
| 베어링 홀더, 필로우 블록, 모터 브라켓 | 프로파일 옆면 | M5 볼트, T너트 |
| 샤프트 | 베어링 구멍 | - |
| 롤러, 브러시, 커플링 | 샤프트 (커플링은 모터 출력축도 가능) | - |
| 모터 | 모터 브라켓 | M3 볼트 (부품표에만 표시) |

- 결합되지 않은 프로파일끼리 파고들면 경고.
- 부품을 옮기면 그 부품에 붙어 있는 것들이 같이 따라온다 (붙어 있는 대상이 전부 같이 움직일 때만).
- 결합 관계는 저장하지 않고 위치로부터 매번 다시 판정한다. scene.json 형식은 그대로다.
- 편집 페이지의 부품표에 프로파일 길이별 개수와 브라켓, 볼트, T너트 개수가 집계된다.

## 기어 연결

1. 샤프트(또는 모터)를 선택하고, Shift+클릭으로 두 번째 샤프트나 모터를 고른다.
2. 오른쪽 패널의 **기어로 연결** 을 누른다.
3. 기어 연결을 선택해서 기어비(앞 : 뒤 회전수)를 입력한다. 1 : 2 는 뒤쪽이 2배 빨라짐(증속).

- 모듈과 잇수는 두 축 사이 거리와 기어비에 맞게 자동으로 정해진다 (잇수 12~150, 모듈 0.5~3). 모듈을 직접 고를 수도 있다.
- 평기어라서 평행한 축끼리만 연결된다.
- 잇수가 정수라 거리가 정확히 안 맞으면 빨간 경고가 뜬다. **거리 맞추기** 를 누르면 다른 규칙을 깨지 않는 선에서 축이나 받침을 옮겨서 맞춘다.
- 기어 위치(축 방향)는 슬라이더로 옮길 수 있다.
- scene.json 의 `links` 에 "어느 축과 어느 축이 몇 대 몇으로 연결됐는지"만 저장되고, 기어 크기는 매번 다시 계산된다.

```json
"links": [
  { "id": "gear-1", "type": "gear", "a": "shaft-roller", "b": "shaft-brush",
    "ratio": [1, 2], "module": "auto", "pos": null }
]
```

## 부품(에셋) 추가하기

`js/assets.js` 의 `ASSETS` 배열에 항목을 추가한다.

```js
{
  id: 'profile-2020',            // scene.json 에 저장되는 이름 (바꾸지 말 것)
  name: '알루미늄 프로파일 2020',  // 화면에 보이는 이름
  category: '프레임',             // 에셋 목록 묶음
  spec: '단면 20 × 20 mm',
  params: {                      // 편집 페이지에서 바꿀 수 있는 치수 (없으면 {})
    length: { label: '길이', unit: 'mm', min: 20, max: 3000, step: 1, default: 600 },
  },
  build: ({ length }) => { /* THREE.Object3D 를 만들어 반환 */ },
}
```

길이가 있는 부품은 로컬 X축 방향으로, 원점이 가운데에 오도록 만든다.
조립 규칙에 참여하려면 `kind` 와 결합점(`mount`, `bore`, `seat`, `front`)을 정의한다. 형식은 `js/assets.js` 맨 위 주석 참고.

## 파일 구성

```text
index.html        보기 페이지
editor.html       편집 페이지
scene.json        현재 기기 배치
js/assets.js      부품 카탈로그
js/scene.js       보기, 편집 페이지 공통 3D 코드
js/assembly.js    조립 규칙 (결합 판정, 자석 스냅, 체결 부품, 부품표)
js/editor.js      편집 기능
js/publish.js     적용 버튼 (GitHub API 로 scene.json 커밋)
js/thumbs.js      에셋 3D 미리보기 사진
images/parts/     부품 실물 사진 (<에셋 id>.jpg)
css/              스타일
vendor/three/     three.js r170 (MIT)
```
