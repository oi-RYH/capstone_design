# 프로젝트명 - 캐리어 자동 청소 및 관리 장치

## 소개
#### 캐리어 자동 청소 및 관리 장치

캐리어의 **몸체와 바퀴를 자동으로 세척**하고, 카메라를 이용해 **외관 파손 여부를 검사**하는 자동 관리 시스템입니다.

단순 세척뿐만 아니라 캐리어의 상태를 확인하고 관리할 수 있는 통합 장치를 목표로 하며,
현재 **몸체 세척, 바퀴 세척, 파손 검사, 지퍼 개방** 기능을 중심으로 설계하고 있습니다.

> 인천대학교 임베디드시스템공학과 캡스톤디자인 프로젝트

## 주요 기능

### 동작 흐름

```mermaid
flowchart TD
    A[캐리어 투입] --> B[캐리어 크기 감지]
    B --> C[캐리어 몸체 세척]
    C --> D[캐리어 바퀴 세척]
    D --> E[카메라 기반 파손 검사]
    E -->|이상 없음| F[지퍼 개방]
    E -->|이상 발견| G[파손 위치 및 검사 결과 표시]
    F --> H[세척 완료]
    G --> H
```

<details>
<summary><strong>캐리어 몸체 자동 세척</strong></summary>

캐리어의 전면, 후면 및 측면을 자동으로 세척하는 기능입니다.

- 캐리어 크기 및 위치 감지
- 브러시를 이용한 표면 세척
- 다양한 크기의 캐리어 대응 구조 검토

</details>

<details>
<summary><strong>캐리어 바퀴 자동 세척</strong></summary>

외부 오염이 집중되는 캐리어 바퀴를 별도로 세척합니다.

- 회전 브러시를 이용한 집중 세척
- 바퀴 회전을 이용한 전체 면 세척

</details>

<details>
<summary><strong>캐리어 파손 검사</strong></summary>

세척 과정에서 카메라를 이용해 캐리어의 외관 상태를 확인합니다.

- 카메라 기반 캐리어 외관 촬영
- 흠집, 균열 등 외관 이상 탐지
- 바퀴 및 손잡이 상태 확인
- 파손 위치 및 검사 결과 표시

</details>

<details>
<summary><strong>캐리어 지퍼 개방</strong></summary>

캐리어의 지퍼를 기계적으로 개방하는 기능을 구현합니다.

- 지퍼 손잡이 고정 방식 설계
- 모터를 이용한 지퍼 이동
- 다양한 캐리어 지퍼 구조 대응 방법 검토

</details>
