# 기존 아이디어 ~ 9/21

### 캐리어 바퀴 청소 아이디어

- **구조**
  - 캐리어 바퀴를 회전시키는 구동 롤러와 바퀴 표면을 청소하는 하강식 회전 브러시로 구성한다.
  - 캐리어의 하중을 이용해 청소 브러시가 내려오는 기계식 연동 구조를 적용한다.

- **장점**
  - 구성 요소가 비교적 적어 구조가 간단하다.
  - 캐리어의 무게를 이용하므로 브러시 하강을 위한 별도의 제어가 필요하지 않다.

- **단점**
  - 유지보수를 위해 구동 롤러를 간편하게 분리하고 청소할 수 있는 탈착 구조가 필요하다.

- **방식**
  1. 캐리어를 장치에 넣고 바퀴를 구동 롤러 위에 위치시킨다.
  2. 장치가 캐리어의 하중을 받으면 청소 브러시가 하강하여 바퀴에 접촉한다.
  3. 구동 롤러와 청소 브러시를 서로 반대 방향으로 회전시켜 바퀴 표면의 오염물을 제거한다.
  4. 브러시 하강은 캐리어의 하중으로 작동하며, 회전 구동 방식은 별도로 설계한다.

### 캐리어 몸체 청소 아이디어

- **구조**
  - 캐리어의 넓은 측면 2면, 좁은 측면 2면, 윗면과 아랫면을 청소하는 롤러 브러시로 구성한다.
  - 아랫면에는 청소 영역에 따라 중형 롤러 브러시와 소형 롤러 브러시를 배치한다.
    - **중형 브러시:** AB 바퀴 쌍과 CD 바퀴 쌍 사이의 중앙 영역을 청소한다.
    - **소형 브러시:** A–B 바퀴 사이와 C–D 바퀴 사이의 좁은 영역을 청소한다.
  - 카메라로 바퀴 위치와 밑면 형상을 파악하여 각 브러시의 이동 범위와 경계를 설정한다.

- **장점**
  - 캐리어의 6면을 대상으로 청소하여 청소 가능한 면적을 최대한 확보할 수 있다.
  - 캐리어보다 조금 큰 크기의 장치를 목표로 설계할 수 있다.

- **단점**
  - 여러 브러시와 이동 장치가 필요하므로 하드웨어 구조가 복잡하다.
  - 브러시의 이동 공간과 구동부를 확보하는 과정에서 장치의 실제 부피가 커질 수 있다.
  - 캐리어마다 바퀴의 위치와 간격이 달라 브러시와 바퀴의 간섭을 방지하기 위한 인식 및 제어가 필요하다.

- **방식**
  1. 캐리어를 장치 내부에 위치시킨다.
  2. 카메라로 밑면 형상과 바퀴 위치를 인식한다.
  3. 인식 결과를 바탕으로 중형·소형 브러시의 청소 영역과 이동 경계를 계산한다.
  4. 각 면에 배치된 롤러 브러시를 이용해 캐리어 몸체를 청소한다.
  5. 밑면은 중형 브러시와 소형 브러시의 담당 영역을 구분하여 청소한다.
  6. 설정된 경계 안에서 브러시를 이동시켜 바퀴와 브러시 사이의 간섭을 줄인다.

## 9/25 — 몸체 청소 방식 변경 검토

몸체 청소 방식으로 **UV 살균**과 **에어를 이용한 먼지 제거**를 검토한다.

### 1. UV 살균

#### 광원별 특징 비교

아래 내용은 현재까지 정리한 비교 내용이며, 실제 특성은 선정 제품의 사양을 확인해야 한다.

| 항목 | UV-C LED 모듈 | 254 nm 계열 램프 |
| --- | --- | --- |
| 배치 방식 | 작은 모듈을 여러 면에 분산 배치하기 용이 | 길쭉한 광원을 세로로 배치하기 용이 |
| 장점 | 긴 수명, 즉시 켜기·끄기 가능, 소형, 특정 영역 집중 조사 가능 | 높은 출력, 비교적 저렴한 가격 |
| 단점 | 높은 가격, 낮은 출력 | 수은 포함, 예열 시간 필요, 비교적 짧은 수명 |
| 수은·오존 관련 | 수은 미포함, 오존 발생 여부는 제품 사양 확인 필요 | 185 nm가 함께 방출되는 제품은 오존 발생 가능 |

#### 광원 선정 시 고려 사항

- **오존이 발생하지 않는 제품을 선정해야 한다.**
- 짧은 파장의 UV는 공기 중 산소에 작용하여 오존을 발생시킬 수 있으므로, 방출 파장과 오존 비발생 사양을 확인한다.
- 254 nm 램프를 후보로 검토하되, 185 nm의 동시 방출 여부를 확인한다.
- 실제 살균 효과와 필요한 조사 시간은 별도 검증이 필요하다.

#### 예상 수량·가격·살균 시간 비교

> 아래 수치는 기존 아이디어에 기재된 예상치이다. 21~24인치 캐리어를 기준으로 하며, 산출 근거와 제품 사양, 실험 조건의 확인이 필요하다.

| 항목 | 255 nm UV-C LED | 254 nm 저압 수은 살균 램프 |
| --- | --- | --- |
| 검토 규격 | 65 mW급 | 15 W급 |
| 예상 수량 | 약 28개 | 약 8개 |
| 개당 예상 가격 | 약 6.8만 원 (기판 장착 모듈) | 약 1만 원 (램프 단품) |
| 예상 살균 시간 | 약 4~7분 | 약 14~25초 |

- **유사 사례 참고:** 바이러스별 평균 약 30초가 소요된 사례를 참고했으나, 출처와 조건은 추가 확인이 필요하다.
- **출력과 시간:** 원안에서는 램프의 출력이 높아 필요한 시간이 짧을 것으로 예상했다. 다만 출력 수치의 의미와 실제 조사 조건을 확인해야 하며, 시간 차이만으로 살균 성능의 우열을 단정할 수는 없다.
- **배치와 사각지대:** 램프는 수량이 적어 사각지대가 생길 가능성을 고려해야 한다. LED는 작은 모듈을 여러 곳에 배치할 수 있어 사각지대를 줄이는 방향으로 설계할 수 있을 것으로 예상한다.

#### 실험으로 확인할 사항

- 캐리어의 굴곡과 광원 배치에 따른 사각지대
- 지퍼 등 재질이 다른 부위의 영향
- 실제 살균 효과와 필요한 조사 시간

### 2. 에어를 이용한 먼지 제거

#### 구현 방식 및 고려 사항

| 검토 항목 | 고려 사항 |
| --- | --- |
| 에어건 사용 | 에어건의 이동 경로를 설계해야 한다. |
| 전체 송풍 | 캐리어 전체에 강한 바람을 보내는 방식을 검토한다. |
| 먼지 포집 | 떨어진 먼지를 모을 팬과 필터를 검토한다. |

#### 장점과 한계

- **장점:** 가벼운 먼지를 제거할 수 있다.
- **한계:** 떨어진 먼지를 포집하지 않으면 다른 부위에 다시 붙을 수 있다.
- **한계:** 액체나 끈적이는 오염물은 제거하기 어렵다.

#### 개인 의견

- 캐리어의 먼지 제거 기능이 꼭 필요한지 검토할 필요가 있다.
- 몸체 청소 브러시와 마찬가지로 예산 부담이 생길 수 있다.
- 먼지 제거 기능을 시연하는 용도로는 의미가 있을 것으로 생각한다.
