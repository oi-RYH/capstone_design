# [ 기존아이디어 ~9/21 ]

## 캐리어 바퀴 청소

### 방법 A - 뜨거운 물로 불리고 세개 롤러로 닦기

- 구조

  - 뜨거운 물로 바퀴를 좀 불린 후 자동세차장 브러쉬로 바퀴 닦기
- 장점

  - 뜨거운 물로 불리면 브러쉬로 닦을 때 더 수월해짐
- 단점

  - 물 사용 자체가 힘들 가능성 높음 (고장 문제 등)
- 이미지

## 캐리어 몸체 청소

### 방법 A - 차량 자동세차장 방식

- 구조

  - 자동세차장처럼 몸체 닦는 방식.
  - 원통형 롤브러쉬가 자동세차장처럼 돌아가면서 캐리어 몸통을 문지르며 닦음.
  - 더 확실한 세척을 위해, 브러쉬 중앙에 소독젤/알코올 소독약을 넣고 브러쉬가 작동시 뿜어내며 브러쉬에 뭍혀 캐리어 몸체를 세척할 수 있도록
- 장점

  - 세차장이랑 비슷한 원리이므로 세척 확률 높을거라 예상함
- 단점

  - 먼지나 다른 오염물은 세척가능할 것 같지만, 비용상 캐리어 오염 중 녹인 고무 같은 오염도 세척할 수 있는 모터를 구할 수 있는가.
- 예상 이미지

  - 분홍색 : 캐리어
  - 네이비 : 캐리어 닦는 브러쉬
  - 연두색 : 소독약을 뿜어내는 통
  - 하늘색 : 소독젤/소독약
