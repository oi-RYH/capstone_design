# 캐리어 자동 세척 기기

**여행 후 캐리어의 바퀴와 쉘을 자동으로 세척하고 외관 상태를 검사하는 기기**

팀원  배정훈 · 김성민 · 김도엽 · 김해수 · 손은성      |      작성일  2026. 9. 28.      |      수행기간  2026년 2학기

## 요약
여행 후 캐리어의 바퀴와 쉘에 묻은 오염물질은 실내로 유입되며, 이를 직접 닦는 일은 번거롭다. 본 프로젝트는 캐리어를 투입하기만 하면 바퀴와 쉘을 자동으로 세척하고, 세척 전후 촬영으로 청결도와 외관 손상을 검사하는 기기를 제작한다. 1차 대상은 20인치 캐리어이며, 모듈 단위 시험 후 실제 캐리어 한 개의 전체 공정을 통합 검증한다. 바퀴 오염 제거율 90% 이상, 파손 탐지율 90% 이상, 평균 처리 시간 5분 이내를 목표로 한다.

## 1 배경과 문제 정의

우리의 캐리어들은 여행을 마치고, 바퀴 혹은 쉘에 야외에서 얻게된 각종 흙·먼지들과 오염 물질을 갖고 집에 들어오게 된다. 이런 문제 상황으로 인해 여행 후 캐리어 세척은 필수 단계이다.

하지만 사람이 일일이 바퀴를 돌려가며 닦고 몸체를 세척하기엔 여행으로 이미 많은 체력을 소모한 상황이 대부분이다. 이 문제를 해결하기 위해 캐리어를 기기에 넣기만 하면 자동으로 세척이 되는 작품을 만들게 되었다.

### 사용자와 사용 환경

- **주요 사용자**  일반 가정의 구성원

- **설치 환경**  가정집

- **확장 환경**  호텔 투숙객 및 호텔 로비 확장 가능

## 2 목표와 범위

자동으로 바퀴·쉘 청소와 청소 품질 및 상태 검사

### 포함 범위 (In-Scope)

- 20인치 캐리어 · 바퀴 세척 · 몸체 세척 · 외관 검사

### 제외 범위 (Out-of-Scope)

- 지퍼 자동 개방

### 설계 체계

구현 계획 수립 과정에서 정의되지 않은 요소가 이후 작업의 위험 요인이 될 수 있다고 판단하여, 제작에 앞서 ① 문제 및 목표 정의 ② 요구사항 정의 ③ 시스템 설계 ④ 검증 및 안전 계획 ⑤ 프로젝트 수행 계획의 다섯 영역으로 설계를 구체화한다.

## 3 요구사항

### 기능 요구사항

- **자동 이송**  캐리어 투입 후 청소 완료까지 자동으로 이송한다.

- **바퀴 세척**  캐리어 바퀴를 자동으로 세척한다.

- **몸체 세척**  캐리어 몸체의 먼지를 자동으로 제거한다.

- **외관 검사**  외관의 손상 또는 파손을 감지한다.

### 비기능 요구사항

- **이송 안정성**  투입구부터 배출구까지 캐리어가 넘어지거나 손상되지 않고 이동해야 한다.

- **바퀴 호환성**  일반적인 캐리어 바퀴 크기에 대응하여 세척을 완료해야 한다.

- **세척 품질**  몸체의 먼지가 육안으로 발견되지 않을 정도로 청소되어야 한다.

- **탐지 중점**  외관 손상 중 바퀴 부분의 손상을 중점적으로 탐지해야 한다.

### 정량 평가 지표와 비교 기준

| 파손 탐지율 | 90% 이상 |

## 4 시스템 설계

### 전체 동작 흐름

1. 부착  사용자가 캐리어를 갈고리에 부착한다.

2. 사전 촬영  세척 전 캐리어 상태를 촬영한다.

3. 바퀴 세척  앞·뒤 바퀴를 순서대로 세척한다.

4. 쉘 세척  캐리어 쉘의 먼지를 제거한다.

5. 사후 검사  세척 후 상태를 촬영하고 파손 여부를 검사한다.

6. 배출  캐리어를 출구로 이동한 뒤 사용자가 회수한다.

### 최소 시험 단위와 인터페이스

- **캐리어 이송 모듈**  이동·정지 명령을 받아 위치 도달·오류를 Main MCU로 보고한다.

- **바퀴 청소 모듈**  세척 시작 명령을 받아 완료·오류를 Main MCU로 보고한다.

- **쉘 청소 모듈**  세척 시작 명령을 받아 완료·오류를 Main MCU로 보고한다.

- **청소 평가 모듈**  1차 Vision. 촬영 명령을 받아 청결도·촬영 완료를 PC와 Main MCU로 전달한다.

- **파손 감지 모듈**  2차 Vision. 검사 시작 명령을 받아 파손 결과·완료를 PC와 Main MCU로 전달한다.

- **Touch UI**  사용자 명령을 받아 Main Controller와 연동해 화면에 표시한다.

### 최소 기능 제품 (MVP)

실제 20인치 캐리어 한 개가 투입부터 배출까지 전체 공정을 수행할 수 있는지 시험하는 것을 MVP로 정의한다. 전체 시스템을 모듈 단위로 분리해 먼저 시험한 뒤, 실제 캐리어 한 개의 전체 공정을 통합 검증한다.

## 6 안전 계획

### 안전 요구사항

- **SR-001**  비상정지 장치를 설치한다.  (예상하지 못한 기계 오작동)

- **SR-002**  작동 중 사용자가 내부에 접근할 수 없어야 한다.  (회전체·이송부 접촉)

- **SR-003**  점검용 도어가 열리면 구동부가 정지해야 한다.  (작동부 접촉)

- **SR-004**  모터에 비정상적인 과부하가 발생하면 정지해야 한다.  (캐리어·청소포 걸림)

- **SR-005**  물 사용 영역과 주요 전기장치를 물리적으로 분리한다.  (누전·합선)

- **SR-006**  캐리어가 정상 위치에 없으면 세척을 시작하지 않는다.  (캐리어 전도·장치 충돌)

- **SR-007**  세척 중 캐리어에 허용 이상의 힘을 가하지 않는다.  (캐리어 파손)

- **SR-009**  오류 발생 시 사용자에게 오류 상태를 알린다.  (잘못된 후속 조작)

### 예상 고장과 대응

- **이송 중 걸림**  캐리어 크기·형상 문제. 모터 전류·위치 센서로 감지해 이송을 정지하고 오류를 표시한다.

- **캐리어 넘어짐**  고정 불량. 카메라·센서로 감지해 전체 공정을 정지한다.

- **바퀴 미회전**  롤러 접촉 불량. 회전 센서·전류로 감지해 세척을 중지하거나 재시도한다.

- **청소포 걸림**  과도한 압착. 모터 전류 증가로 감지해 모터를 즉시 정지한다.

- **촬영 실패**  가림·통신 오류. 이미지 수신을 확인해 재촬영한다.

- **파손 검사 실패**  판별 신뢰도 부족. Confidence 기준으로 재촬영하거나 검사 실패를 표시한다.

- **도어 개방**  오작동·사용자 행동. Door Sensor로 감지해 모든 구동부를 정지한다.

## 7 기대효과

- **세척 부담 감소**  바퀴를 직접 돌려 닦는 수작업 없이 캐리어 투입만으로 세척을 마칠 수 있다.

- **실내 오염 감소**  바퀴와 쉘의 흙·먼지를 실내 유입 전에 제거한다.

- **파손 조기 확인**  세척 전후 촬영으로 바퀴 중심의 외관 손상 여부를 확인할 수 있다.

## 8 향후 확정 사항

- **범위 정리**  건조 기능 포함 여부, 쉘 세척 방식 확정

### 산정 기준
