      사이트에 적용

      적용하려면 레포에 쓸 수 있는 GitHub 토큰이 한 번 필요합니다. 이 브라우저에만 저장되고 레포에는 올라가지 않습니다.

      1. GitHub 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
      2. Personal access tokens → Tokens (classic) → Generate new token (classic)
      3. Note 에 이름(예: 캐리어 편집기), Expiration 은 기간을 정하고, 권한은 public_repo 하나만 체크
      4. Generate token 후 나온 ghp_ 로 시작하는 값을 아래에 붙여넣기

      레포 주인이 아닌 팀원은 먼저 레포 협업자(Settings → Collaborators)로 초대받아야 합니다.
